  top 8 exact singular values : [0.966  0.9332 0.9174 0.9016 0.8862 0.871  0.8561 0.8416]
  their multi-indices         : [(1, 0, 0), (2, 0, 0), (0, 1, 0), (3, 0, 0), (1, 1, 0), (4, 0, 0), (2, 1, 0), (0, 2, 0)]
  linear direction e_1 (rho = 0.9660) sits at spectral position 1
  linear direction e_2 (rho = 0.9174) sits at spectral position 3
  linear direction e_3 (rho = 0.7870) sits at spectral position 14
  rank-3 truncation keeps [(1, 0, 0), (2, 0, 0), (0, 1, 0)]
  condition rho_1^2 < rho_r*:  0.9332 < 0.7870  =>  exactness at d = r* FAILS
  exact RMS truncation error of E[Theta|Y] by rank:
      d =   1: 1.2087
      d =   2: 1.2087
      d =   3: 0.7870
      d =  13: 0.7870
      d =  14: 0.0000  <- exact
      d =  16: 0.0000  <- exact
  => exactness needs d >= 14, NOT d >= r* = 3.

  The reason: the top-d directions are ordered by singular value, and a
  nonlinear Hermite direction of a strongly correlated canonical pair
  (sigma = rho_1^2, rho_1^3, ...) can outrank a weakly correlated LINEAR
  direction (sigma = rho_j). Truncating at r* then drops a linear
  direction that E[Theta|Y] needs.

  The sharp statement: rank-d truncation recovers E[Theta|Y] exactly iff
      d >= #{ a != 0 : prod_i rho_i^{a_i} >= rho_{r*} },
  which collapses to d >= r* exactly when rho_1^2 < rho_{r*} -- the first
  case above. Otherwise the requirement is strictly larger, as in the
  second, and it grows quickly as rho_1 -> 1.

  The spectrum is recovered well, and sigma_1 to a few parts in a thousand.
  The posterior mean is not: direct regression wins by a wide margin here,
  which is the sharp form of the remark that rank-one truncation and direct
  regression differ. On a Gaussian model the Hermite tail crowds the linear
  directions out of the top of the spectrum, so the rank needed for the
  posterior mean is far above r* (see check 3). When only one functional is
  ever wanted, regress on it directly; the operator earns its cost when many
  functionals are queried after training.
